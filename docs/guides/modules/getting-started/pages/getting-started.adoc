= Quickstart guide
:page-platform: Cloud
:page-description: A quickstart guide for adding a project to CircleCI and exploring some features

This quickstart provides a guided tour through setting up a project, collaborating, and tools to iterate on and debug your build configuration. In this section, you will learn how to:

* Create a project and connect some existing code to CircleCI.
* Invite team members to collaborate on your new project.
* Use the VS Code extension to debug and extend your config.
* SSH into a build to debug your project.

To view a full list of CircleCI `config.yml` options, go to xref:reference:ROOT:configuration-reference.adoc[Configuration reference].

== Prerequisites

* A CircleCI account. You can link:https://circleci.com/signup/[sign up for free].
* A code repository you want to build on CircleCI.

NOTE: This guide assumes you have xref:first-steps.adoc[signed up] and connected to GitHub, Bitbucket or GitLab.

image:guides:ROOT:getting-started-guide-exp/create-project.png[float=right]
[%hardbreaks]
*Create a project*
In the CircleCI web app, select link:https://app.circleci.com/projects[Projects] from the sidebar. Select *Create project*, then choose the repository you would like to connect from the dropdown.

If you cannot locate the org selector in the top left corner to find the correct organization.

image:guides:ROOT:getting-started-guide-exp/select-config-gitlab.png[float=right]
[%hardbreaks]
*Select a config.yml*
In the *Select your link:https://circleci.com/docs/config-start/[config.yml] file* modal, select *Fast*, name your project, and select *Create Project*. If you are authenticated through the GitHub App, you also need to set up SSH access for your project at this point.

{empty} +

image:guides:ROOT:getting-started-guide-exp/change-config-gitlab.png[float=right]
[%hardbreaks]
*Edit CircleCI config*
You are now in the <a class="no-external-icon" link:https://circleci.com/docs/config-editor/#getting-started-with-the-circleci-config-editor[CircleCI config editor], pre-populated with a sample `config.yml` file. You can change this config for an alternative by selecting *Change: Hello World*.

{empty} +

image:guides:ROOT:getting-started-guide-exp/commit-run-gitlab.png[float=right]
[%hardbreaks]
*Commit your config*
Select *Commit and Run*. This will create a `.circleci/config.yml` file at the root of your repository on a new branch called `update-circleci-config`.

{empty} +

image:guides:ROOT:getting-started-guide-exp/pass-pipeline.png[float=right]

You should soon have a passing pipeline. If you are happy with this configuration, merge it into your main branch, or continue to make changes.

== 2. Dig into your first pipeline

image::guides:ROOT:getting-started-guide-exp/quick-start-second-step.svg[section two banner image]

*Explore your passing pipeline and invite your teammates to join you, for free. By collaborating, you can troubleshoot, get pull requests approved, build and test faster.*

image:guides:ROOT:getting-started-guide-exp/steps.png[float=right]
[%hardbreaks]
*So, what just happened?*
Expand your workflow and select a job to view the steps that ran. Use the tabs along the top to access test results, timing data, artifacts, and resource usage metrics.

{empty} +
{empty} +

image:guides:ROOT:getting-started-guide-exp/expand-step.png[float=right]
[%hardbreaks]
*View step output*
Expand any step to view the build output. You can search, share or download the output for collaboration and debugging. If a step fails, use the xref:toolkit:intelligent-summaries.adoc[Explain this error] button for help.

{empty} +
{empty} +

image:guides:ROOT:getting-started-guide-exp/invite.png[float=right]
[%hardbreaks]
*Invite teammates*
Invite teammates to collaborate on your projects. Go to *Organization Settings* > *People* to generate invites and get further instructions. Collaborators can view and follow your projects. Teammates can create a free CircleCI account at any time to view your pipelines, even if they are not committing any code.

== 3. Debug and iterate

image::guides:ROOT:getting-started-guide-exp/quick-start-third-step.svg[section three banner image]

*Discover CircleCI features to help debug and configure your builds.*

image:guides:ROOT:getting-started-guide-exp/ssh-rerun.png[float=right]
[%hardbreaks]
*Rerun with SSH*
To access a job's build environment for troubleshooting, rerun the job with SSH access. The VM remains active for 10 minutes after the pipeline finishes. For full details, refer to the xref:execution-managed:ssh-access-jobs.adoc[Debug with SSH] page.

{empty} +
{empty} +

image:guides:ROOT:getting-started-guide-exp/validate-config.png[float=right]
[%hardbreaks]
*VS Code extension*
Using the xref:toolkit:vs-code-extension-overview.adoc[CircleCI VS Code extention], validate your CircleCI config file. Get help with troubleshooting config updates and help keeping dependencies up to date.
